# YACHATDAC website — information we need from you

*Last updated: 14 September 2026*

The new website is built. A few places still show a gap where a real detail belongs, such as an email
address, a name or a document. This form gathers every one of them in one go, so we only need to ask
once.

**How to fill it in**

- Write your answer after the colon, replacing the line `________`.
- Tick a box by changing `[ ]` to `[x]`.
- If you don't know an answer yet, leave it blank. That's fine, and we'll keep that spot marked on the site.
- Send files (PDFs, photos) with your reply. Tick "attached" so we know to look for them.
- Send the finished form back to **August**.
